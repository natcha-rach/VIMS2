# ระบบหลังบ้านร้านเสื้อยืดมือสอง

ระบบไว้ใช้เอง (ไม่มี login เพราะใช้คนเดียว) สำหรับติดตาม:
- ต้นทุน/เงินทุนแต่ละล็อต + แก้ไข/ลบล็อตได้
- สต็อกเสื้อแต่ละตัว + แก้ไข/ลบ/ยกเลิกการขาย (คืนสต็อก) ได้
- การขาย + ตัดสต็อกทันที (เหมาะกับใช้หน้างานถนนคนเดินผ่านมือถือ)
- กำไร/ขาดทุน แยกตามล็อตและวิธีจ่ายเงิน (เงินสด / เงินโอน / โครงการรัฐบาล)
- รายงานสรุปยอดรายวัน/เดือน/ปี
- **บัญชีครบวงจร**: ค่าใช้จ่ายอื่นๆ, กำไรสุทธิหลังหักค่าใช้จ่าย, กระแสเงินสด, สมุดบัญชีเงินเข้า-ออกทั้งหมด, ส่งออก CSV
- **ระบบแบ่งถังเงิน**: ตั้ง % แบ่งเงินหลังขายเป็น 4 ถัง (เก็บต้นทุน/ใช้หนี้/สำรอง/ค่าใช้จ่ายอื่น) คำนวณจำนวนเงินให้อัตโนมัติ
- **เมนูแบบ sidebar (hamburger)**: กดไอคอน ☰ เปิด/ปิดเมนูด้านซ้ายได้ หรือกดปักหมุดให้เปิดค้างไว้ตลอด

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1. สมัคร Supabase (ฟรี)
1. ไปที่ https://supabase.com สมัครสมาชิก แล้วสร้าง Project ใหม่ (เลือก region สิงคโปร์จะเร็วสุดสำหรับไทย)
2. รอ Supabase สร้าง database เสร็จ (ประมาณ 1-2 นาที)

### 2. สร้างตารางข้อมูล
1. ในหน้า Project เข้าเมนู **SQL Editor** (แถบซ้าย)
2. **ติดตั้งใหม่ครั้งแรก:** เปิดไฟล์ `sql/schema.sql` คัดลอกทั้งหมด วางใน SQL Editor แล้วกด **Run** (ได้ตารางครบทุกตัวรวมระบบบัญชี+ถังเงินเลย)
   **เคยติดตั้งไปแล้วก่อนหน้านี้:** รันเพิ่มตามที่ยังไม่มี — `sql/migration_add_expenses.sql` (ตาราง expenses) และ/หรือ `sql/migration_add_settings.sql` (ตาราง app_settings สำหรับถังเงิน) ไม่กระทบข้อมูลเดิม
3. ตรวจสอบที่เมนู **Table Editor** ว่ามีตาราง `lots`, `items`, `sales`, `expenses`, `app_settings` ขึ้นมาแล้ว

### 3. เชื่อมต่อเว็บกับฐานข้อมูล
1. ในหน้า Project เข้าเมนู **Project Settings > API** (หรือ **Data API** / **API Keys** ถ้า UI เป็นแบบใหม่ หรือกดปุ่ม **Connect** มุมขวาบน)
2. คัดลอกค่า **Project URL** และ **anon public key** (หรือ publishable key แบบใหม่)
3. เปิดไฟล์ `assets/js/supabaseClient.js` แก้บรรทัดนี้:
   ```js
   const SUPABASE_URL = "YOUR_SUPABASE_URL";
   const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
   ```

### 4. เปิดใช้งาน
เปิดไฟล์ `index.html` ด้วย Live Server ใน VS Code หรือ deploy ขึ้น Netlify (ต่อกับ GitHub) เพื่อใช้งานผ่านมือถือได้ทุกที่

## วิธีใช้งาน

1. **เพิ่มล็อต** (หน้า "ล็อต") — ทุกครั้งที่รับเสื้อมาใหม่ บันทึกล็อตพร้อมต้นทุนรวม แก้ไข/ลบได้จากปุ่มในการ์ดแต่ละล็อต
2. **เพิ่มสินค้า** (หน้า "สินค้า") — แยกเสื้อแต่ละตัวจากล็อต กำหนดต้นทุน/ราคาขาย แก้ไข/ลบได้ และถ้าขายไปแล้วมีปุ่ม **"ยกเลิกการขาย"** เพื่อคืนเข้าสต็อกกรณีบันทึกผิด
3. **ขายของ** (หน้า "ขายของ") — แตะที่เสื้อ → ใส่ราคาขายจริง → เลือกวิธีจ่ายเงิน → ยืนยัน (ตัดสต็อกทันที)
4. **ภาพรวม** — เงินทุนรวม ยอดขาย กำไร/ขาดทุน สต็อกคงเหลือ (ตั้งแต่เริ่มขายจนถึงตอนนี้)
5. **รายงาน** — สรุปยอดขาย/กำไร แยกรายวัน/เดือน/ปี พร้อมตารางแนวโน้มและรายการที่ขาย
6. **บัญชี** — หน้าใหม่สำหรับทำบัญชีแบบครบวงจร:
   - บันทึก**ค่าใช้จ่ายอื่นๆ** ที่ไม่ใช่ต้นทุนเสื้อ (ค่าเช่าแผง, ค่าเดินทาง, ค่าถุง ฯลฯ) แก้ไข/ลบได้
   - **กำไรสุทธิ** = ยอดขาย − ต้นทุนของที่ขายไปแล้ว − ค่าใช้จ่ายอื่นๆ (ตัวเลขบัญชีจริง)
   - **กระแสเงินสดสุทธิ** = เงินที่ได้จากการขาย − เงินที่จ่ายไปทั้งหมด (รวมของที่ยังไม่ขายด้วย) บอกว่าเงินสดในมือตอนนี้เป็นบวก/ลบเท่าไหร่
   - **สมุดบัญชี** — ตารางเดียวรวมทุกการเคลื่อนไหวเงิน (รับล็อต / ค่าใช้จ่าย / ขาย) เรียงตามวันที่ พร้อมยอดคงเหลือสะสม
   - ปุ่ม **ส่งออก CSV** เอาสมุดบัญชีไปเปิดใน Excel/Google Sheets ได้ทันที
   - **ระบบแบ่งถังเงิน** — ตั้ง % 4 ถัง (เก็บต้นทุน / ใช้หนี้รายเดือน / สำรอง / ค่าใช้จ่ายอื่น) ต้องรวมกันได้ 100% ระบบคำนวณจำนวนเงินแต่ละถังให้ทันที โดยดีฟอลต์คำนวณจากยอดขายรวมทั้งหมด แต่แก้เป็นยอดอื่นได้ (เช่น ยอดขายวันนี้) กด **"บันทึกเปอร์เซ็นต์นี้ไว้ใช้ครั้งหน้า"** เพื่อจำค่าไว้ ไม่ต้องตั้งใหม่ทุกครั้ง

## เมนู sidebar (hamburger)

กดไอคอน **☰** มุมซ้ายบน (มีทุกหน้า) เพื่อเปิดเมนู จะเลื่อนออกมาจากด้านซ้าย:
- แตะที่พื้นหลังมืดๆ หรือปุ่ม ✕ เพื่อปิดเมนู
- ติ๊ก **"📌 เปิดเมนูค้างไว้"** ด้านล่างเมนู เพื่อปักหมุดให้เมนูเปิดค้างตลอด (เหมาะกับใช้บนคอมพิวเตอร์หน้าจอกว้าง) — ระบบจำค่านี้ไว้ในเครื่อง/เบราว์เซอร์นั้นๆ ครั้งหน้าเปิดมาจะปักหมุดไว้เหมือนเดิม (ถ้าเปลี่ยนเครื่อง/เบราว์เซอร์ต้องตั้งใหม่)

## จุดที่ต่อยอดได้ในอนาคต (แนะนำเพิ่มเติม)

- **รูปภาพสินค้า** — ใช้ Supabase Storage (ฟรี) ถ่ายรูปเสื้อแนบตอนเพิ่มสต็อก ช่วยให้จำง่ายเวลาขาย
- **ป้ายราคา/QR code** — พิมพ์ QR ติดเสื้อแต่ละตัว สแกนแล้วขึ้นหน้าขายทันที ไม่ต้องเลื่อนหา
- **แจ้งเตือนสินค้าขายช้า** — เสื้อที่อยู่ในสต็อกนานเกิน N วัน ขึ้นเตือนในหน้าภาพรวม เผื่อลดราคาระบาย
- **เป้าหมายยอดขายรายเดือน** — ตั้งเป้าไว้ในหน้ารายงาน แล้วโชว์ % ที่ทำได้แล้ว
- **กราฟแนวโน้ม** — เปลี่ยนตารางในหน้ารายงาน/บัญชีเป็นกราฟเส้น/แท่ง (ใช้ Chart.js เพิ่มได้ไม่ยาก)
- **ระบบลูกค้าประจำ** — เก็บชื่อ/เบอร์ลูกค้าไว้ ดูได้ว่าใครซื้อซ้ำบ่อย
- **สำรองข้อมูล** — ตั้งเวลา export ตาราง lots/items/sales/expenses เป็น CSV เก็บไว้กันเหตุ (Supabase มี backup ให้อยู่แล้วในแผนเสียเงิน แต่ export เองไว้อุ่นใจกว่า)
- **หน้าร้านออนไลน์** — ต่อยอดจากตาราง items เดิม ให้ลูกค้าดูสินค้าเองได้ (ตามที่คุยไว้ตั้งแต่ต้น)
- **ย้ายไป React** — โครงสร้างไฟล์แยก JS ตามหน้าที่ไว้แล้ว ย้ายง่ายขึ้นเมื่อพร้อม

บอกได้เลยว่าอยากได้อันไหนก่อน จะช่วยต่อให้ทีละอย่าง
